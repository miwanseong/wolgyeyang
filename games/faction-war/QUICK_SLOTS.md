# 인벤토리와 퀵슬롯

I로 배낭을 열고 소지품을 전체·소비·재료·도구·씨앗·기타로 거른다. 실제 장비 인스턴스는 장비 탭, 신선도별 음식 묶음은 음식 탭, 개체 물고기는 물고기 탭에서 관리한다. 검색/정렬/상세 사용을 유지하고 도구 선택은 도구 분류에서 표시한다. 이전 스타일 규칙이 아이콘 칸을 겹치게 만들던 문제도 수정했다.

1~8은 아이템·기술·장비를 함께 쓰는 퀵슬롯이다. 배낭 아이콘 또는 습득한 기술을 창 아래 슬롯으로 드래그해 지정한다. 슬롯을 다른 슬롯으로 드래그하면 서로 교환한다. 우클릭 또는 초점 상태 Delete/Backspace로 비운다. 아이템/기술 상세의 슬롯 번호 선택은 드래그 대체 조작이다. 키 자체는 설정 탭에서 변경한다. 모바일은 4×2 배치를 사용한다.

HTML 모달이 열린 동안 바깥 HUD는 비활성 상태가 되므로 배낭과 기술창 안에도 같은 슬롯을 표시한다. 모든 슬롯은 서버 캐릭터 상태를 공유하고 저장/재접속 후 유지한다. 키 설정은 기존처럼 브라우저별이다. 이전 세 기술 슬롯은 최초 이전에만 읽고 새로운 혼합 슬롯 UI를 사용한다. H 회복 단축키는 호환용으로 유지한다.

서버가 보유 아이템/장비, 습득한 직업 기술, 슬롯 범위와 교환 전 내용을 검증한다. 사용 시 수량·쿨다운·자원·행동 시간을 다시 판정한다. 신선도별 음식은 현재 가방의 해당 음식 중 오래된 묶음을 찾아 사용하므로 만료된 묶음 ID를 영구 저장하지 않는다. 빈 도구는 소모되지 않고 손에 든다. 수량이 0인 슬롯은 보관하되 사용을 거부한다.

획득 기록은 서버가 인벤토리·장비·개체 물고기·브론즈 증가를 비교해 본인의 최근 80건에 남긴다. 전체 채팅에 함께 보이고 획득 탭으로 따로 볼 수 있다. 다른 플레이어의 획득 기록·퀵슬롯은 공개하지 않는다. 단순히 화면의 수량 변화를 보고 획득 기록을 만들어내지 않는다.
