# 괭이로 준비하는 경작지

괭이를 손에 들고 마을 밭 1.8칸 이내에서 E를 누른다. 준비되지 않은 밭이면 1초 동안 괭이를 들어 내려찍고 흙을 당기는 밭 갈기를 한다. 네 기본 직업 각각 8프레임, 총 32셀의 동일 의상 SD 시트를 사용한다. 발 위치는 도구 끝이 아니라 작성된 발 기준선을 따르며, 도구를 스프라이트에 그렸으므로 별도 3D 괭이를 겹쳐 그리지 않는다.

타격 시점에 흙 입자와 효과음을 연결한다. 완료되면 밭의 흙고랑을 표시하고 괭이 내구도 1/농사 숙련 1을 반영한다. 씨앗은 아직 쓰지 않는다. 작물을 고른 뒤 E를 다시 눌러 심는다. 성장/물주기/수확은 기존 작물 규칙을 따른다. 수확이나 시든 작물 정리 뒤에는 다음 파종 전에 다시 밭을 간다. 이미 자라는 기존 저장 작물은 준비된 밭으로 이전한다.

작업은 서버가 시간/원래 위치/도구/밭 점유를 검사해 완료한다. 클라이언트가 완료 시각이나 작업 ID를 위조해도 끝낼 수 없다. 이동·피격·접속 종료·전투 전환·운영자 강제 이동은 작업과 점유를 해제한다. 취소한 작업은 씨앗과 완료 내구도를 소비하지 않는다. 다른 플레이어가 같은 밭을 동시에 갈 수 없다. 서버 재시작 때 미완료 작업/임시 점유는 초기화한다.

괭이 내구도는 80, 물뿌리개는 100이며 물주기 성공 시 0.5를 사용한다. 파손 시 작업을 거부하고 대장간에서 수리한다. 농사 UI는 해당 도구를 들고 실제 작업 거리 안에 있을 때만 나온다. 작업 중에는 텍스트와 진행 막대를 표시한다. 작물 자체의 성장/시듦 단계와 계절 규칙은 유지한다.

아트는 우측 기본/반전 동작을 공유한다. 모든 방향의 독립적인 도구 보행/파종/물주기 시트를 새로 완성했다는 뜻은 아니다.
