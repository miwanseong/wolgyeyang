# 연속 이동·전투·변경 마을 갱신

## 조작과 이동

WASD/방향키는 시간 기반 연속 이동이다. 클라이언트 예측과 서버 충돌 판정을 공유하며 입력 순서·320ms 입력 만료·대각 속도 정규화를 적용한다. 다른 플레이어는 상태 사이를 보간한다. 짧은 방향 입력도 공격 방향에 반영한다. 화면의 2D 전환 버튼은 제거하고 기본 2.5D를 유지한다.

I는 분류·검색·정렬·장비·음식·물고기·성장·설정을 묶은 가방, C는 장비, K는 기술, M은 지도다. 아이템 상세에서 사용·도구 장착·H 빠른 사용 지정을 한다. 농사는 괭이/물뿌리개를 들었을 때만 관련 조작을 표시한다. Enter는 채팅이며 채팅 패널에서 전체/파티 대화와 파티 관리를 한다. 키는 설정에서 변경할 수 있다.

## 전투와 동작

동/남/북 공격 시트 각 32셀(네 직업 × 여덟 프레임), 서쪽은 동쪽의 반전이다. 피격 16셀, 적 동작 32셀, 공격 VFX 32셀과 보조 기술 VFX 32셀을 추가했다. 기본 타격은 예비 동작 뒤 실제 접촉 시점에 앞쪽 범위만 판정하며, 공격 방향·검격·피격·밀림·카메라·히트스톱을 연결한다. 흑백 강조는 공격 시작이 아닌 실제 타격에 맞춰 흰 화면·검은 실루엣·붉은 접촉선을 표시한다. 회피는 예약 타격을 취소한다. 쓰러짐과 귀환도 분리한다.

숲의 뿌리 멧돼지와 폐허의 종 수호자에게 직선 돌진/원형 공격 예고, 체력 절반 이하 2단계, 보스 체력 표시를 추가했다. 돌진은 순간 이동하지 않고 경로를 따라 움직인다. 모든 기술이 독립적인 전체 방향 전용 시트를 가진 상태는 아니다. 직업별 공격/시전 계열과 기술별 효과를 공유한다.

## 장소

변경 마을을 우물 광장·주거 골목·성문 시장·붉은 등불 골목으로 나눈다. 건물을 앞뒤로 어긋나게 놓고 14개 실내 출입구까지 길을 연결한다. 정육점·빵집·성문·흙집·등불 살롱을 추가했다. 포장/흙길/부서진 길을 구분하고 숲길은 굽은 동선으로 바꿨다. 새 소품 시트 32셀과 이야기 조사 지점 20곳을 사용한다. 첫 조사는 서버가 거리와 중복을 검증해 기록/경험치를 지급한다. 노점과 가게마다 판매 품목을 나누며 비 오는 날 흙집 실내에는 누수가 보인다.

원작 국가들의 수도 전체나 원작 NPC 전원의 최종 디자인·대화가 완성된 것은 아니다.

## 성능

지형과 소품의 거리 제외를 유지하고 예고 메시를 재사용한다. 픽셀 그림자와 수목/소품의 가벼운 조명 재질을 사용한다. 소프트웨어 GPU에서는 내부 해상도·그림자 크기·근거리 조명 수를 낮추되 논리 좌표와 카메라 크기를 유지한다. 일반 GPU의 지형 재질과 금속/수면 반사는 유지한다. 모든 기기의 60fps를 보장하지 않는다.

## 저장과 운영

무료 시즌 패스와 외형 미리보기는 MONETIZATION.md를 따른다. 실제 과금은 없다. 무료 Render의 로컬 저장은 재배포나 인스턴스 교체 시 소실될 수 있으며 영구 DB는 아직 연결하지 않았다. 개인 집·플레이어 교환·길드·장편 원작 이야기·전체 고유 모션은 후속 작업이다.

## 검증 기록

Node 서버 테스트 56개 통과. 실제 브라우저에서 지연 입력을 추가한 연속 이동, 방향 공격, 도구 조건 UI, 가방 탭, 채팅 내 파티 생성/파티 대화와 모바일 가로 넘침을 검증했다. 별도 전투/마을 브라우저에서 실제 접촉의 흰/검은/붉은 화면 픽셀, 보스 예고/피격, 성문 노점 조사, 패스 20단계와 흙집 누수를 확인했다. 장기 경제·대규모 동시 접속 검증은 포함하지 않는다.
