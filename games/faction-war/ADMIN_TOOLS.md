# 운영자 작업실

운영자 계정 로그인 후 메뉴 → 운영 관리에서 연다. 초기 운영자명은 배포의 ADMIN_USERNAME, 비밀번호는 ADMIN_PASSWORD 설정값이다. 비밀번호를 소스나 공개 응답으로 노출하지 않는다. 일반 계정이 버튼을 직접 만들거나 HTTP 요청을 위조해도 운영 명령은 거부한다.

## 연결한 기능

대상 계정을 고르고 다음 명령을 실행한다.

- 정의된 아이템 123종의 수량 지급(한 번 1~999, 보유 999 상한).
- 장비 기반/희귀도 선택 생성, 60개 보관 한도 준수.
- 낚시 부품 29종 선택 지급(소유 중복 방지).
- 체력·기력·마나·생존 자원과 부상 회복, 무적 켜기/끄기.
- 실제 통행 가능한 지역/좌표로 이동, 현재 이상 레벨 50까지 설정.
- 해당 직업 기술 최대 등급, 요리 40종 해금, 장비/도구 수리.
- 시험용 늑대·해골·두 보스 생성, 가까운 시험용 개체만 제거.
- 맑음/비/바람/더위/자동 날씨, 계절·시각 설정.
- 계정 차단/해제, 강제 접속 종료, IP 차단/해제와 기간·사유.

무적은 일반 공격·보스·생존 피해를 막는다. 상태는 본인 HUD에 표시하고 저장한다. 시험 후 직접 끈다. 일반 플레이어가 장비/기술 요청에 GM 필드를 붙여도 적용하지 않는다. 운영자 대상 조작도 기록한다. 생성과 환경 작업까지 최근 500개 작업 기록을 비공개 계정 파일에 보관하며 화면에는 최근 100개를 보여준다. 세계 정보와 계정 파일은 운영자 인증 없이 다운로드할 수 없다.

## IP 판정과 차단

기본 TRUST_PROXY_HOPS=0은 소켓의 실제 연결 IP만 사용하고 X-Forwarded-For를 무시한다. Render 배포 YAML은 앞단 HTTP 프록시 한 홉을 사용하도록 TRUST_PROXY_HOPS=1을 명시한다. 이 경우 헤더의 오른쪽 마지막 IP를 사용하므로 사용자가 붙인 앞쪽 주소를 신뢰하지 않는다. 호스팅 경로를 바꾸면 실제 프록시 홉 수를 확인한 뒤 설정해야 한다. 관리 화면은 현재 기준과 계정의 마지막 로그인 IP를 표시한다.

차단 IP는 형식/IPv6 표기를 정규화한다. 운영자 접속 주소와 현재 작업자의 주소는 차단할 수 없다. 공유 IP 차단은 같은 주소를 사용하는 다른 이용자에게도 영향을 준다. 지정 주소의 세션을 폐기하고 연결을 닫으며 해당 IP의 인증/게임 API 요청을 거부한다. 로그인 화면과 정적 자산 자체는 제공한다. IP 변경을 통한 재접속까지 방지하는 기기 차단은 아니다.

기본 수명은 UI에서 1시간/24시간/7일/무기한으로 선택한다. JSON 저장과 계정/차단 기록은 재시작 뒤 유지하지만 무료 Render 로컬 저장의 재배포 소실 제한은 그대로다. 영구 운영용 데이터베이스와 백업은 별도 작업이다.
