# 사용자 제공 음악과 효과음

사용자가 업로드한 원본 26개를 public/assets/audio/user에 복사했다. BGM 16곡과 효과음 10개이며 직접 합성한 소리의 저작물 표기와 구분한다. 파일 내용은 변경하지 않았다. MANIFEST.json에 길이·바이트 수·SHA-256을 기록했고 ffprobe로 모두 해석 가능한 것을 확인했다.

BGM은 마을·집/여관·숲·산지·습지·유적·심해·야간·낚시·위험 상태에 배치했다. 나머지 곡까지 인벤토리의 BGM 선택에서 수동 재생할 수 있다. BGM 음량과 효과음 음량은 독립이다. 긴 곡은 AudioBuffer에 전부 디코딩해 쌓지 않고 HTMLAudio 스트리밍으로 재생한다. 두 재생기를 사용해 1.6초 교차 페이드하고, 반복 직전 다음 재생기를 미리 로드한다. 서버는 MP3/WAV MIME과 HTTP 단일 바이트 범위 요청을 처리한다.

문 열기·버튼·닫기·타격·입질·실패·전시 등에 사용자 효과음을 연결했다. 기존 직접 합성 16개에 낚시 던지기/챔질/포획/줄 손상/릴 반복음·흙 작업·채집망 소리 7개를 추가했다. 합성 재현 스크립트는 tools/generate_audio.py다. 효과음은 서로 독립된 소스로 중첩 재생하고 반복음은 페이드한다.
