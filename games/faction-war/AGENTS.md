# 진영전쟁 작업 규칙

시각 자산을 만들거나 바꾸기 전에 ART_DIRECTION.md를 읽는다. 특히 마지막 「NPC 포함 그림체 통일」 절을 따른다. NPC·플레이어·초상은 동일한 SD 도트 그림체다. public/assets/directional-sprites.png를 직접 참조하며 기존 NPC 시트를 스타일 기준으로 사용하지 않는다. 인물 개성은 보존하되 비율·선·음영·픽셀 밀도를 통일한다. 사용자 제공 세계관 인물을 신규 주민 디자인으로 대체하지 않는다.

최우선: 사용자가 제공한 원작 NPC 디자인을 범용 주민으로 대체하지 않는다. ART_DIRECTION.md의 마지막 원작 인물 목록과 원본 이미지를 기준으로 작업한다. 신규 주민 SD 재제작 시트도 원작 반영 완료가 아니며 현재 업로드 보류다.

최신 교정: 점눈은 허용한다. 사용자의 아름다운 디자인 요구는 특히 옷·소품·실루엣의 완성도다. COSTUME_DIRECTION.md를 읽고 얼굴만 계속 수정하지 않는다. 미구현 기능은 SYSTEM_BACKLOG.md와 CONTENT_STATUS.md에 사실대로 기록하고 실제 UI/서버/플레이 흐름을 연결한다.
