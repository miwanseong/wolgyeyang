# 물길의 수첩

## 조작

시장이나 제작에서 손매듭 낚싯대를 얻으면 기본 낚싯대·코르크 찌·삼실 줄이 낚시 장비함으로 한 번 변환된다. 손 도구에서 낚싯대를 들고 다리 옆 물가 또는 해안에서 E로 던진다. 낚시 수첩의 던지기 버튼은 낚싯대를 장착한 뒤 던진다.

입질 표시 때 SPACE 또는 화면 버튼으로 챔질한다. 이후 누르면 막대가 올라가고 놓으면 내려간다. 물고기를 초록 막대에 유지해 포획 게이지를 채운다. 장력 과다·입질 놓침·시간 초과·이동·피격·접속 종료는 실패 처리한다. 모바일은 누르고 놓는 버튼을 사용한다. 기존의 자동 대기 후 보상 방식은 제거했다.

## 어종과 개체

- 별도 이름·서식지·난도·행동·길이 범위·종 희귀도·출현 계절/시간을 가진 128종이다. 접두사 조합을 어종 수에 포함하지 않는다.
- 변경의 강·숲 계류·초원 물길·산악 냉수역·해안·습지·섬의 조수 수로·심해의 8개 분류에 16종씩 있다. 심해 낚시는 호흡복과 심해 대응 낚싯대·줄이 필요하다.
- 종 희귀도는 흔함/드묾/희귀/영웅/전설, 개체 품질은 보통/동빛/은빛/금빛/오색이다. 두 분류는 별개다.
- 모든 개체에 UUID, 접두사, 길이(cm), 무게(kg), 품질, 포획 시각·장소, 완벽한 제어 여부를 저장한다. 접두사는 8종이고 길이·살집에 실제 배율이 있다.
- 보관함은 200마리다. 도감은 팔거나 방생한 뒤에도 종별 횟수·최대 길이·최대 무게·최고 품질을 기억한다.

128개 어종에 별도 셀을 가진 32종×4개 도트 아틀라스를 사용한다. 일부 생성 시트는 균일한 행 간격과 다르므로 asset-layout.js의 실제 소스 경계를 사용한다.

## 낚시 장비

낚싯대 5종, 찌 12종, 줄 12종을 별도 소유·장착·수리한다. 낚싯대의 제압력과 찌의 제어 보정은 막대 크기를 바꾸고, 입질 속도는 기다림을 줄이며, 릴 속도는 포획 진척을 빠르게 한다. 행운은 희귀 어종 가중치·접두사 범위·품질에 영향을 준다. 대물 보정은 큰 개체 구간을 뽑을 확률을 높인다.

허용 무게는 낚싯대와 줄 중 약한 한계에 부력 보정을 적용한다. 초과 중량은 장력을 더한다. 탄성은 장력 손실을 줄인다. 각 부품은 100 내구도로 관리하고 던질 때 소모되며, 줄이 버티지 못하면 추가 마모된다. 구입은 시장, 수리는 대장간에서 한다. 최종 수치는 fishing-gear.js에 있다. 룬·심연 낚싯대는 같은 계열 원화에 색 보정을 적용한다.

## 전시와 활용

보관함의 들어 자랑하기를 누르면 12초 동안 실제 소유 개체를 꺼낸다. 같은 지역의 다른 플레이어에게도 물고기와 길이·무게가 보인다. 길이는 단조 증가하는 표시 크기로 반영하며, 초대형은 시야를 가리지 않도록 로그 곡선으로 압축한다. 살집 보정은 표시 두께에 반영한다. 이동·공격은 전시를 접는다.

시장에서는 개체별 가치로 판매하고, 화덕에서는 민물/바다 생선살로 손질한다. 방생도 가능하다. 서버 소유 개체 ID를 검증하고 한 번만 제거한다. 클라이언트가 길이·품질·보상·성공 점수를 보내도 사용하지 않는다. 미니게임의 위치·진척·장력은 서버가 100ms 간격으로 계산한다.


## 실제 수면과 동작

fishing-water.js의 수면 판정은 강·해안과 포장된 다리를 구분한다. 플레이어 가까이의 실제 수면으로 던질 좌표를 정하고 통행 불가능한 지형 너머/내륙/실내에서는 시작하지 않는다. 찌가 땅에 놓인 채 대기하는 좌표 구간 판정은 제거했다. 강 양쪽과 다리 위에서도 닿는 수면이 있을 때만 가능하다.

캐릭터별 투척/대기/챔질/릴 감기 8프레임, 총 32셀을 연결했다. 잡고 있기만 한 낚싯대는 낚시 중 자세로 표시하지 않는다. 실제 낚시 중에만 수면의 찌와 파문/물보라, 손의 낚싯줄과 동작을 표시하고 중단하면 정리한다. 주변 플레이어도 낚시 동작과 찌/줄 종류를 볼 수 있지만 대상 물고기 ID·개체값·미니게임 상태는 받지 않는다.

## 찌와 줄의 추가 선택

찌 12종은 코르크·깃털·황동·월광·수정·갈대·도토리·등불·연꽃·빙정·뇌우·혼불이다. 각각 수면용 정상/입질 2상태 스프라이트를 사용한다. 장착한 종류가 실제 수면과 장비창 양쪽에 표시된다. 낚싯줄은 삼실·비단·합사·은룬·심압·아마·밀랍 비단·장선·거미비단·해초·용힘줄·혼결 12종이다. 추가 줄 7종은 별도 원화 아이콘을 사용하고 수면 줄의 색도 구분한다.

세 슬롯의 장착 요약과 낚싯대/찌/줄 탭으로 전체 29종을 나눠 본다. 상점 구입/소유 장착/내구도/수리 판정은 유지한다. 운영자 작업실에는 정의된 낚시 부품 지급을 추가했고 획득 채팅에도 남긴다.

## 희귀도 난이도

어종의 원래 난도에서 장비 제압력과 숙련을 반영한다. 희귀도가 높을수록 추적 막대가 좁아지고, 챔질 시간이 줄며, 움직임 폭/속도와 놓쳤을 때의 진척 손실이 커진다. 포획 진척 증가도 느려진다. 최저 막대 폭은 0.13, 최대 제어 보정은 0.14이며 전설의 제한 시간은 최대 40초다. 줄 장력에는 중량 초과와 탄성을 따로 적용한다. 개체 품질 등급은 잡은 뒤 계산하며 어종 희귀도와 혼동하지 않는다.

검증: 실제 브라우저에서 장착한 혼불 찌/용힘줄의 수면 표시와 세 종류 장비 탭, 내륙 시작 거부, 비모달 미니게임/희귀도 안내/취소 시 정리를 확인했다. 서버 시험에서는 실제 수면/다리 구분, 희귀도별 난이도 증가, 소유권·수리·장비 조합·개체 중복 방지와 비공개 상태를 검증했다.
