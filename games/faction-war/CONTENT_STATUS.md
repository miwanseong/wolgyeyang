# 현재 테스트 빌드의 구현 범위

이 문서는 구현된 기능과 남은 제작을 구분한다. 여러 상용 RPG의 전체 콘텐츠를 완성했다는 의미가 아니다.

| 분야 | 동작하는 범위 | 남은 제작 |
|---|---|---|
| 캐릭터 성장 | 네 직업, 누적 경험치·레벨·경험치 바, 능력치 네 종류, 레벨당 능력치 2점, 퀘스트·히든 전직 | 종족 선택과 고유 종족 능력, 외형 커스터마이즈, 장편 직업 스토리 |
| 장비 | 주무기·상의·신발·성유물, 개별 인스턴스, 5등급 희귀도, 접두 효과, 장비별 강화 +10, 내구도·수리·분해 | 세트 장비, 보석·인챈트, 외형 투영, 바닥 전리품 줍기 |

## 아트와 동작

네 기본 직업의 SD 디자인을 기준으로 이동 16셀, 상호작용 16셀, 전투 16셀 아틀라스를 제작했다. 걷기·달리기·채집/파종·물주머니·차징·공격/회복 자세·피격에 연결한다. 여러 생활 동작은 아직 같은 무릎 꿇기 자세를 공유한다. 완성된 모든 동작 애니메이션이라고 표시하지 않는다. 원작 NPC 전원의 최종 방향별 아트와 초상은 미완성이고 거부된 초상은 배포하지 않는다.

아이템 정의·아이콘 60종, 별도 장비 아이콘 8셀, 기술 아이콘 16셀, 지역 소품 8셀, 계절/생태 바닥 4셀을 사용한다. 직접 합성한 로컬 WAV 16종은 중첩 재생·반복음 페이드·음량 설정을 지원한다. 외부 소리 묶음을 다운로드한 것은 아니다.

## 성능과 저장

캐릭터 주변의 작은 지형지물을 거리로 제외한다. 3D 활성 시 2D를 중복해서 그리지 않는다. 반사는 가까운 하나, 환경 캡처는 150프레임 간격, 렌더 상한은 30fps다. 서버 AI는 100ms, 주기 상태 전송은 200ms이고 행동 결과는 즉시 전송한다. 입력은 이전 이동 요청이 끝나야 다음 이동을 보내도록 한다. 기기별 성능과 최대 동시 접속은 별도 부하 검증이 필요하다.

무료 Render의 로컬 데이터 저장은 영구 저장소가 아니다. 재배포·인스턴스 교체 시 소실될 수 있다. 장기 운영용 데이터베이스·백업·분산 월드·10년치 콘텐츠는 구현되지 않았다.
