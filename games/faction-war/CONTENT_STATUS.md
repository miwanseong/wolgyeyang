# 현재 테스트 빌드의 구현 범위

이 문서는 구현된 기능과 남은 제작을 구분한다. 여러 상용 RPG의 전체 콘텐츠를 완성했다는 의미가 아니다.

## 아트와 동작

네 기본 직업의 SD 디자인을 기준으로 이동 16셀, 상호작용 16셀, 전투 16셀 아틀라스를 제작했다. 걷기·달리기·채집/파종·물주머니·차징·공격/회복 자세·피격에 연결한다. 여러 생활 동작은 아직 같은 무릎 꿇기 자세를 공유한다. 완성된 모든 동작 애니메이션이라고 표시하지 않는다. 원작 NPC 전원의 최종 방향별 아트와 초상은 미완성이고 거부된 초상은 배포하지 않는다.

아이템 정의·아이콘 123종, 별도 장비 아이콘 8셀, 기술 아이콘 16셀, 지역 소품 8셀, 계절/생태 바닥 4셀을 사용한다. 직접 합성한 로컬 WAV 24종은 중첩 재생·반복음 페이드·음량 설정을 지원한다. 외부 소리 묶음을 다운로드한 것은 아니다.

## 성능과 저장

캐릭터 주변의 작은 지형지물을 거리로 제외한다. 3D 활성 시 2D를 중복해서 그리지 않는다. 반사는 가까운 하나, 환경 캡처는 150프레임 간격, 렌더 상한은 30fps다. 서버 AI는 100ms, 주기 상태 전송은 200ms이고 행동 결과는 즉시 전송한다. 이동은 입력 방향/순서/만료를 서버에서 검증하고 클라이언트 예측과 상태 재조정을 사용한다. 기기별 성능과 최대 동시 접속은 별도 부하 검증이 필요하다.

무료 Render의 로컬 데이터 저장은 영구 저장소가 아니다. 재배포·인스턴스 교체 시 소실될 수 있다. 장기 운영용 데이터베이스·백업·분산 월드·10년치 콘텐츠는 구현되지 않았다.

## 최신 갱신 — 낚시·모션·대화·사운드

- 스택 아이템 정의는 현재 123종이고 개체 어종 128종은 별도 보관함·도감으로 관리한다. 낚시 장비는 3슬롯/15종, 어종 희귀도 5단계와 개체 품질 5단계, 접두사 8종이다. 자세한 규칙은 FISHING.md에 있다.
- 자동 낚시 보상을 제거하고 서버 판정 막대 추적 미니게임, 개체별 측정값·기록·판매·손질·전시를 연결했다.
- E는 고정 농사가 아닌 손 도구 사용이다. 괭이·물뿌리개·낚싯대·채집망을 장착해야 해당 행동을 할 수 있다. 전투는 무기를 준비하고 전시는 접는다.
- 정면/후면/측면 이동 32셀, 대각 이동 32셀, 회피 16셀, 낚시/전시 8셀을 추가했다. 달리기는 방향 프레임의 빠른 재생과 속도 보정이며 방향별 전용 달리기 전체 애니메이션은 아직 미완성이다.
- 보통 주민 7명과 훈련관은 각각 다른 외형을 사용한다. 대화에는 같은 인물 원화의 초상 크롭을 표시한다. 이들은 게임용 신규 NPC이며 원작 등장인물 최종 아트를 대체하지 않는다.
- 문/창문 16셀을 사용하고 출입에 짧은 여닫기 시간을 연결했다. 실내 창문 근처에서 덧창을 여닫을 수 있다. 수목 4종, 계절·시간별 곤충 4종의 관찰 기록, 낚시·곤충·농사를 연결하는 첫 마을 이야기 의뢰를 추가했다. 전체 장편 스토리는 미완성이다.
- 채팅은 상시 보이는 별도 패널이다. 일상 공격·회피마다 뜨던 성공 알림은 줄였다. 주민 가까이에서 R 또는 클릭으로 대화한다.
- 겹친 도로 패치를 단일 메시로 합쳤다. 이동 위치를 선형 보간하고 발 기준을 투명 여백까지 보정했다. 스킬 VFX는 직업별 네 계열의 16셀 아틀라스로 재생한다. 흑백 타격은 흰 바탕·검은 실루엣·붉은 타격선, 레벨업은 금빛 상승 효과·표시·소리다. 모든 기술에 개별 완성 VFX가 있는 상태는 아니다.
- BGM/효과음 구성은 USER_AUDIO.md에 있다. 합성 소리 24개와 사용자 파일 26개를 구분해 사용한다.

브라우저 검증에서 낚시 성공·개체 전시·대각 이동·회피·NPC 초상·문 출입·BGM 자동/수동 재생을 확인했다. 흑백 연출은 화면 픽셀의 흰 영역·검은 실루엣·붉은 타격선으로 확인했고 실제 경험치 상승 후 레벨업도 확인했다. 최대 동시 접속이나 모든 기기에서의 프레임 성능을 보장한 것은 아니다.


## 최신 시스템 작업

- 최대 4명 파티 생성·근거리 초대·60초 만료·본인 수락/거절·탈퇴·추방·파티장 위임·전용 채팅·체력/지역/접속 표시를 추가했다. 초대는 본인만 수락할 수 있고 중복 합류·정원 초과를 서버가 차단한다. 보상 분배·협동 퀘스트·길드는 아직 미구현이다.
- 신규 SD 주민 시트와 얼굴 중심 블랙 시안은 연구물로 보관하고 이번 배포에서 제외했다. 기존 NPC 원작 반영 미완성 상태는 그대로다. 사용자 최신 지시는 점눈 허용, 의상·소품·전체 실루엣 디자인의 완성도 강화다.


## 최신 갱신 — 야영 식탁과 요리 수첩

요리 40종, 기본/수업/요리책/탐험/의뢰 해금, 미발견·발견·습득 도감과 제작 기록을 구현했다. 불 근처에서 1~20회 조리·대체 재료·필요 도구·물·장작·완료 시 소비를 판정한다. 모닥불 생선 손질/직화구이, 냄비·팬·주전자·절임병과 마을 오븐을 구분한다. 품질·회복·종류별 효과 교체, 묶음별 신선도/부패·보냉 보관, 선택 판매·일일 주문을 연결했다. 상세 규칙과 아직 공유하는 동작 범위는 COOKING.md에 있다. 인벤토리 품목 123종, 요리/재료 아이콘 64셀과 추가 작물 16셀, 합성 장작 반복음을 추가했다.

요리 통합 후 서버 테스트 49개 및 두 종류의 실제 브라우저 검증(야영 조리·모바일 수첩, 기존 NPC/인벤토리/키 설정/출입)이 통과했다. 다른 플레이어의 필드 좌표는 공개 아바타 정보로 유지하고 식품 묶음·기록·재산은 본인에게만 보낸다.

## 2026-11-02 — 혼합 퀵슬롯·기술 지도·운영 도구

I 배낭의 소비/재료/도구/씨앗/기타 분류와 장비 탭, 1~8 혼합 퀵슬롯(아이템/기술/장비 드래그·교환·지정·해제·서버 저장)을 연결했다. 획득 기록은 본인 채팅에만 표시한다. QUICK_SLOTS.md 참고.

K 기술창은 넓은 연결 지도로 바꾸고 직업별 택일 변형 8종을 실제 범위/피해/흡혈/감속/회복 판정에 연결했다. SKILL_TREE.md에 조건과 아직 공유하는 아트 범위를 기록했다.

운영자 전용 아이템/장비 생성·회복·무적·좌표 이동·레벨·직업 기술/요리법 해금·수리·시험 몬스터 생성/제거·계절/시간·날씨·계정 차단/종료·IP 차단을 추가했다. 서버 역할 검증·작업 기록·접속 주소 판정/정규화·세션 폐기를 검증했다. ADMIN_TOOLS.md 참고.

3D 캐릭터 옆의 중복 금속 검 막대와 2D 대체 화면의 예전 기하학 검격을 제거했다. VFX는 8프레임 전체를 45ms 간격으로 재생하며 헛친 공격/지원 마법은 피해 타격용 흑백 플래시와 히트스톱을 발생시키지 않는다. 모든 원작 NPC 아트와 변형별 독립 모션이 완성된 것은 아니다.

## 2026-11-02 — RPG UI와 수면 낚시

RPG_UI.md의 상태/지도/전투/채팅/메뉴 도크와 배낭 좌측 탐색/기술창 공통 틀을 적용했다. 낚시는 실제 수면을 검증하며 비모달 조작창·32셀 동작·줄·파문·물보라를 표시한다. 찌 12종/줄 12종/낚싯대 5종, 찌 24셀과 추가 줄 아이콘 8셀 중 7종을 연결했다. 희귀도에 따른 챔질 시간/막대 폭/추적/장력/진척을 구분한다. 상세와 공유하는 방향 동작 범위는 FISHING.md를 따른다. 원작 NPC 전원의 최종 아트를 제작했다는 의미는 아니다.

밭 갈기 갱신: 준비 전 밭 → 1초 괭이 동작 → 준비된 흙고랑 → 파종의 순서와 이동/피격/접속 종료 취소·공유 밭 점유를 연결했다. 네 직업의 전용 32셀, 흙 입자·접촉 소리·작업 진행 막대를 사용한다. FARMING.md에 자원/내구도/취소와 아직 공유하는 방향 동작 범위를 기록했다.
