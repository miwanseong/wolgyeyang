# RPG 인터페이스 정리

## 플레이 화면

좌상단은 캐릭터 초상·이름·레벨·HP/MP/기력이다. 생활 상태는 펼쳐 보는 항목으로 묶되 허기/갈증/산소 부족과 부상에 주의를 표시한다. 경험치 막대는 화면 아래로 분리한다. 우상단은 지역명·길/건물/강이 그려진 미니맵·시각·확대 배율이다. 미니맵을 누르거나 M으로 여행 지도를 연다. 좁은 화면에서는 지도를 접고 필요한 때 펼친다.

하단 중앙의 혼합 퀵슬롯과 기본 전투 조작을 하나의 도크로 묶었다. 채팅은 좌하단, 가방/기술/수첩/메뉴는 우하단이다. 주변 상호작용은 작은 펼침 메뉴로 제공하며 기존 R 조작은 유지한다. 농사 조작은 괭이/물뿌리개를 들고 밭 작업 거리 1.8칸 안에 왔을 때만 표시한다. 밭 갈기 동작/진행/취소는 FARMING.md를 따른다. 낚싯대를 들고 내륙에 있으면 던지기를 비활성화한다. 먼 NPC/건물 이름 표시는 줄인다.

## 창

배낭은 좌측 탐색·우측 아이템 분류/검색/목록/상세·하단 공유 퀵슬롯의 고정 틀이다. 좁은 화면에서는 탐색을 가로 탭으로 바꾼다. 기술창도 같은 제목/본문/하단 슬롯 구조를 사용하고 포인트 안내를 한 줄로 묶는다. 로그인 그림과 원작 캐릭터 디자인은 바꾸지 않는다.

인터페이스 배치는 public/rpg-ui.js와 public/rpg-ui.css에서 관리한다. 기존 기능 노드를 복제하지 않고 이동하므로 기존 클릭/키 설정/드래그/운영자 권한 처리가 유지된다. 미니맵의 정적 지형은 캐시하고 플레이어 표식만 갱신한다.

## 낚시가 보이는 UI

화면을 가리던 낚시 모달을 작은 비모달 측면 조작창으로 바꿨다. 수면의 찌·낚싯줄·파문·물방울과 캐릭터 동작을 계속 볼 수 있다. 기다림/입질/줄다리기를 구분하고 입질 후 어종 희귀도와 난이도 1~5를 표시한다. SPACE와 모바일 누르기/놓기는 그대로 사용하고 ESC/낚시 접기로 중단한다. 자세한 수면 판정·장비·난이도는 FISHING.md를 따른다.

PC 1440, 태블릿 1024, 모바일 390 크기에서 주요 HUD 패널의 겹침/화면 밖 이탈과 배낭/기술 드래그를 검증한다. 모든 모바일 실기 환경의 성능을 보장하는 문서는 아니다.
