# 넓은 기술 지도와 선택 변형

K를 열면 1560×1120 크기의 연결 지도를 스크롤하거나 빈 공간을 끌어 탐색한다. 확대/축소/중앙 버튼, 선행 연결선, 잠김/습득 표시, 공통·직업 특성과 직업 기술, 하단 공유 퀵슬롯을 제공한다. 기존의 좁은 4장 카드 나열을 바꾼 독자 UI다. 특정 게임의 규칙 전체를 이식한 것은 아니다.

기술 포인트 TP와 특성 AP는 구분한다. 직업 기술 16종/3등급과 기존 AP 특성을 유지한다. 레벨 6·해당 기술 2등급·2 TP를 충족하면 직업별 아래 두 갈래 중 하나를 택한다. 한 캐릭터는 변형 하나만 선택하며 현재 되돌리기는 없다.

| 직업 | 선택 | 실제 변화 |
|---|---|---|
| 검사 | 폭풍 검로 | 초승 베기 범위 4, 피해 85%, 광역 형태 |
| 검사 | 핏빛 서약 | 초승 베기 피해 80%, 실제 가한 피해 25% 회복 |
| 마법사 | 재꽃의 분열 | 잔불을 주변 3칸 폭발로 변경, 피해 75% |
| 마법사 | 겨울 낙인 | 잔불을 냉기 단일 공격으로 변경, 피해 85%, 6초 감속 |
| 사냥꾼 | 낙엽 탄막 | 관통시를 주변 3칸 탄막으로 변경, 피해 75% |
| 사냥꾼 | 가시 심장 | 가시 덫 경직 0.9초·감속 6초 |
| 장인 | 피난의 룬 | 룬 수복 회복량 +15, 방어 효과 10초 |
| 장인 | 해체 연금술 | 투척탄 폭발 3.5칸, 피해 85% |

모든 조건·효과는 서버에서 계산한다. 기술 아이콘을 드래그하거나 슬롯 번호를 선택해 배치한다. 효과와 판정의 변화까지 연결했지만, 각 변형 전용 새 원화와 완전히 독립적인 방향별 모션 시트는 아직 제작하지 않았다. 장기 실전 밸런스는 후속 검증이다.
