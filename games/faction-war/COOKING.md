# 불빛 아래의 식탁

이번 요리 작업의 중심은 모험 중의 식사다. 생선 손질·직화구이·냄비 요리·차를 모닥불 곁에서 준비할 수 있다. 시장 판매와 일일 음식 주문은 선택 기능이다. 원작에 없는 음식·재료·조리 도구는 게임용 보충 콘텐츠다.

## 조리법 40종

- 기본 7종: 시골 빵, 따뜻한 곡물죽, 잿불 감자, 여행자의 고기꼬치, 숲향 약초차, 산딸기 한 줌, 소금구이 생선.
- 여관주인 수업 9종: 변경 스튜, 들버섯 수프, 허브 오믈렛, 버터 팬케이크, 어부의 맑은탕, 콩과 채소 한 냄비, 모닥불 사과 조림, 건조 여행식, 훈연 육포. 여관주인 근처에서 요리 숙련 2와 12 브론즈로 각각 배운다.
- 책 3권 / 12종: 「화덕과 반죽」 「오래 두는 식탁」 「해안의 한 냄비」. 시장에서 구입해 수첩에서 읽는다. 중복 구입·읽기는 차단한다.
- 탐험 기록 8종: 숲 (50,16), 고개 (40,76), 폐성 (38,43), 해안 (115,86)의 기록을 직접 찾아 읽는다. 먼 거리에서 요청해 해금할 수 없다.
- 주민 의뢰 전수 4종: 농부·여관주인·약초사·잡화상의 기존 의뢰를 완료하고 해당 주민 근처에서 배운다.

미발견·발견·습득을 구분한다. 미발견 요리는 이름/재료를 숨기고 발견 경로를 안내한다. 습득한 요리는 누적 생산 수, 조리 횟수, 최고 품질, 최초/최종 제작 시각을 기록한다. 숙련은 기존 생활 경험치로 1~10이며 수업/책/탐험/의뢰 조리법의 실제 조리에는 각각의 숙련 조건도 적용된다.

## 길에서 만드는 식사

모닥불은 기존 꾸러미 설치를 사용한다. 3.2칸 이내에서 직화·냄비·팬·주전자·절임병 요리를 할 수 있다. 캠프 주인은 제한하지 않으므로 동료의 불도 함께 이용할 수 있다. 오븐 요리는 여관 실내 또는 마을 공동 화덕에서만 가능하다.

직화에는 별도 냄비가 필요 없다. 냄비/팬/주전자/절임병은 지참해야 한다. 냄비와 주전자는 조리 1회당 물주머니 물 1회분, 야영 조리는 5회당 목재 1개를 사용한다. 모닥불 설치 꾸러미에는 부싯돌을 쓰고, 추가 장작은 조리 과정에서 소모한다. 조리 도구는 반복 사용하며 소모하지 않는다. 잡은 개체 물고기도 모닥불에서 생선살로 손질할 수 있고 기본 소금구이 조리법은 처음부터 안다.

1~20회 수량 선택과 최대 가능 수량, 허용 대체 재료 선택을 지원한다. 원재료·물·장작·도구·숙련·장소·출력 수량 한도를 서버가 검사한다. 조리 시간은 2초 + 추가 1회당 0.25초다. 완료 시 다시 조건을 검사하고 한 번만 재료를 소비한다. 이동/피격/명시적 취소/서버 재시작은 미완성 조리를 취소한다. 재시작 시 진행 중인 조리를 보상 없이 취소해 중복 생성하지 않는다. 식사도 1.2초의 동작을 거친다. 기존 craft/cook/eat/sell 경로도 새 조리/식품 규칙으로 연결했다.

## 재료와 품질

버섯·양파·달걀·우유·버터·향신료·양배추·다시마·조개살·쌀·콩·고추·서리 열매·잔불 고추·달빛 소금·밀가루를 추가했다. 보통 재료는 시장, 희귀 재료는 지역 채집으로 얻는다. 양파·양배추·벼·콩의 씨앗과 네 성장/시듦 단계도 연결했다.

품질 4단계: 소박한 / 정성 담긴 / 훌륭한 / 명작. 요리 숙련·소모 재료 품질·신선도·작은 장인 보정·제한된 난수가 영향을 준다. 오래된 재료부터 소비하고 새 재료와 섞는다고 기존 재료 수명을 갱신하지 않는다. 농사/채집 숙련은 새 재료 묶음의 품질에 영향을 준다. 품질 배율은 회복·음식 효과·판매가에 1 / 1.12 / 1.25 / 1.4이며, 신선도 25% 미만 식품의 회복 효과는 추가로 0.7배다.

식사·간식·음료 효과는 각 종류 한 개씩, 3분이다. 같은 종류는 교체하고 지속시간을 무한 합산하지 않는다. 음식 효과는 기존 전투 능력치/기력·마나 회복 경로에 반영한다. 회복량은 최대 체력/허기/갈증을 넘지 않는다.

## 보관과 부패

인벤토리 수량과 식품 묶음은 동기화한다. 묶음은 개별 ID·품목·수량·품질·만든 시각·유통 수명·보관 위치·직접 조리 여부·재료 기준 원가를 갖는다. 기존 계정의 식품도 처음 접근할 때 기본 품질과 해당 식품의 수명으로 이관한다. 보관 중 시간이 지나면 기존 묶음 수명은 유지된다.

가방 수명은 현실 시간 기준으로 재료/요리에 따라 20분~24시간이다. 게임 접속을 끊어도 시간이 흐른다. 보존식·절임·잼은 12~24시간이다. 룬 보냉 상자를 챙겨 집/여관/산림집/창고 실내에서 보관하면 남은 수명의 진행이 2.5배 느려진다. 보냉 보관은 최대 200개, 식품 묶음은 최대 192개, 가방 품목당 999개다. 보관/회수 시 남은 수명 비율을 보존해 반복 입출고로 신선도가 회복되지 않는다.

상한 식품은 수량에서 제거하고 부패 기록에 쌓는다. 먹기·팔기·납품할 수 없다. 상한 식품 3개는 퇴비 1개로 돌릴 수 있다. 신선 식품의 일반 노점 입출고는 차단하고 식품 보관함/판매 경로를 사용한다. 개체로 보관 중인 물고기는 기존 어류 보관함 규칙을 유지하며, 손질된 생선살부터 신선도를 관리한다.

## 선택 경제

식품 보관함에서 시장에 가져가 판매한다. 개별 품질·신선도가 판매가에 반영되고 재료 기준 원가를 표시한다. 이는 실제 구매 영수증 기반 회계가 아닌 재료 평가액이다. 월드 하루마다 주문 3개를 생성하며, 수락 → 직접 조리한 가방 음식 → 품질/신선도/수량 검사 → 1회 납품 순서다. 구입한 식품이나 다른 사람의 묶음 ID로 보상을 받을 수 없다.

## 화면·연출·검증

상단 「요리 수첩」에서 조리/해금/기록/보관을 관리한다. NPC 대화에서도 수첩을 열 수 있다. 음식 40종·재료 16종·씨앗 4종·도구 4종의 64셀 도트 아틀라스, 추가 작물 16셀을 사용한다. 야영 중에는 불빛, 국물을 젓는 도구와 김, 직화 꼬치 소품을 보여주고 가까운 불의 합성 장작 소리는 페이드하며 반복한다. 자동 BGM은 가까운 야영 불에서 「따뜻한 기억」으로 전환하되 위험/낚시 상태를 우선한다. 캐릭터 자세는 기존 SD 상호작용 시트를 사용하며 음식 40종마다 독립된 전신 애니메이션을 만든 것은 아니다.

단위 테스트는 조리량·장소·물/장작·도구·해금·대체 재료·품질·효과 중첩·신선도·보관 수명 보존·반복 보상/개인 정보 차단을 확인한다. HTTP 테스트는 실제 모닥불 손질→조리→이동 취소→재조리→식사→저장/재시작을 확인한다. 브라우저는 야영 3D, 생선 2회 조리, 회복, 대체 재료 죽, 수첩과 모바일 넘침을 확인한다. 무료 호스팅의 영구 저장 문제는 이 기능과 별도다.
