# 미완성 시스템과 검증 기준

완성된 상용 RPG 전체 구조를 구현했다고 주장하지 않는다. 동작하는 기존 범위는 CONTENT_STATUS.md, 아래는 실제 플레이 흐름까지 추가해야 하는 항목이다.

1. 파티: 이번 변경에서 생성/초대/수락/거절/4인 제한/탈퇴/위임/추방/전용 대화/체력 표시를 연결했다. 보상 분배·공동 퀘스트는 아직 없다. 다른 파티 초대 위조와 전용 대화 누출을 서버에서 차단해야 한다.
2. 개인 집·건축: 소유권·설치 가능한 구역·충돌·재료 소모·회수·보관함·저장/재접속을 함께 구현해야 한다. 집 이미지만 늘리는 것은 구현 완료가 아니다.
3. 연애·일정: 현재 선물 친밀도에 NPC 일과·조건부 대화·관계 단계·개인 이벤트를 연결해야 한다. 원작 인물의 관계를 임의로 확정하지 않는다.
4. 전투/전직: 전직별 고유 기술, 보스 패턴, 피격/회피/기술 방향별 동작과 독립 VFX, 적정 거리/쿨다운/직업별 실전 검증이 필요하다.
5. 경영/교환: 가상 노점과 상단 장부 외에 플레이어 간 양측 확정 교환·취소/접속 끊김 처리·개체 아이템 소유권 검증이 필요하다.
6. 세계와 이야기: 원작 인물의 실제 배치와 대화·의뢰, 국가별 장소, 여행 중 발견과 장기 진행을 연결해야 한다. 범용 주민을 원작 인물 구현으로 셈하지 않는다.
7. 운영: 영구 DB·백업/복구·동시접속 부하 검증과 무료 테스트의 임시 저장 문제는 별도 작업이다.

각 작업은 코드 존재, 조작 가능한 UI, 성공/실패/중복 요청/저장 상태 검증을 분리해서 기록한다. 새 이미지 생성 수를 시스템 완성도로 보고하지 않는다.
