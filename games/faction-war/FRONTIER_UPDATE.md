# 외곽 생활·의뢰 표시·PvP·성능 갱신

## 배치와 그림

서쪽 순찰자 헤른, 숲길 채집꾼 리에, 목초지 목동 토렌, 해안 등대지기 오델을 추가했다. 신규 변경 주민이며 원작 캐릭터를 대체하지 않는다. 기존 NPC 시트를 공유하는 임시 외형이다. 지역별 NPC 대화/의뢰를 서버 근접 판정과 연결했고, 순찰길과 야영지 접근 지점은 충돌 나무에서 비운다. 수레, 점심자리, 보급 천, 목책, 훈련장 수칙 등 다섯 흔적은 조사 시 이야기와 최초 탐험 경험치를 준다.

frontier-greenery.png는 투명 4×2 픽셀 환경 아틀라스다. 관목·야생 풀·흰 꽃·갈대·열매 관목·고사리·마른 풀·푸른 꽃을 길 주변 군락으로 배치한다. 도로/물/문/충돌 지점/PvP 바닥을 비우고 가까운 개체만 그린다. 일부 풀은 비충돌 장식이고 채집 가능한 식물은 기존 채집 노드로 구분한다. 원작 인물 아트가 완성됐다는 의미가 아니다.

의뢰는 플레이어별로 금색 ! 수락 가능, 회색 ? 진행 중, 청록 ! 보고 가능을 표시하며 완료 후 지운다. 전직·기록관·재료 의뢰를 포함한다. 실제 대화 이름에도 상태가 보인다.

대각선 시트의 행 경계를 실제 그림에 맞추고, 북서쪽은 북동쪽의 뒤쪽 프레임을 반전해 사용한다. 북서 전용 새 독립 작화가 아니다. 구르기 소리는 옷 스침/마찰/착지음을 직접 합성했고, 승인 직후 재생하여 SSE 지연을 기다리지 않는다. tools/generate_roll.py로 재현한다.

## PvP 시험 구역

변경 마을 서쪽 폐훈련장: x40~64/y90~108, 입구 x51/y87. 주변 상호작용에서 참가를 선택한다. 양쪽 동의, 같은 구역, 생존/접속, 참가 후 3초를 서버에서 검사한다. 일반 공격/화염술/피해 기술을 연결했고 회피와 직업별 재사용 시간은 기존 규칙을 따른다. 피해는 원 피해 45%에서 방어를 일부 반영하고 대상 최대 체력 18%로 제한한다. 이는 초기 시험 밸런스이며 장기 경쟁 밸런스 검증은 아니다.

패배하면 참가를 해제하고 체력을 회복해 입구로 돌아온다. 골드/경험치/아이템 손실이나 PvE 처치 보상은 없다. 비참가자/구역 밖/오프라인 캐릭터는 공격할 수 없다. 교전 후 5초간 참가 해제를 막는다. 구역 경계와 HUD로 참가 상태를 표시한다.

## 렉 개선과 검증

고정 충돌물은 지역별 캐시, 나무는 주변 공간 버킷으로 검사한다. 전 지역의 모든 나무를 이동 하위 단계마다 순회하지 않는다. 지역 전환 시 공용 아틀라스 재질/텍스처를 폐기하던 부분을 막았다.

일반 GPU는 DPR 1에서 시작해 지속적인 느린 프레임에서만 정수 2배 확대를 사용한다. 소프트웨어 GPU는 정수 2배에서 시작해 필요하면 3배로 전환하며 최근접 표시와 HTML HUD 해상도를 유지한다. 호환 모드에서는 동적 그림자 맵/큐브 환경 캡처를 끄고 주변광·근거리 광원을 사용한다. 일반 GPU는 동적 그림자를 유지한다. 물 반사 캡처는 최대 초당 10회로 제한하고 환경 캡처를 매 150프레임 반복하지 않는다.

동일 Chromium 소프트웨어 GPU, 1440×1000, 마을 정지 상태 5초 표본에서 RAF 프레임 간격 중앙값 약 267ms → 33ms, 95백분위 약 300ms → 50ms. 다른 실제 기기 성능을 보장하지 않는다. 전체 서버 테스트 74개 통과. 브라우저에서 북서 이동/반전, 가까운 풀숲, 외곽·숲 NPC 대화, 의뢰 상태 전환/완료 제거, PvP HUD, 구르기 WAV 응답과 JS 오류 없음을 확인했다.

## 저장

사용자 요청에 따라 새 영구 저장/브라우저 복구 기능은 이번 변경에서 제외했다. 기존 임시 서버 저장 동작은 유지한다. Render 무료 서비스 재배포로 계정/캐릭터 파일이 사라지는 문제는 영구 저장을 연결하기 전까지 남아 있다.
