# 대륙 기반 재구성 — 2026-11-02

이 문서는 기존 게임 전체를 새로 완성했다는 보고가 아니다. 기존 서버의 계정·인벤토리·농사·낚시·요리·전투를 유지하면서 지형/공간/표시 구조를 교체하는 첫 통합 작업이다. 새 국가의 완성된 도시, 모든 NPC 원화, 전 방향의 신규 동작 시트, 모든 과거 요청의 완료를 주장하지 않는다. 환경 설정은 변경하지 않는다. 게임 배포는 사용자의 최신 명시적 요청에 따라 진행한다.

## 실행 구조

- `continent.js`: 원작 국가와 게임용 지리를 분리한 지역 정의, 대륙 연결 좌표, 양방향 통행, 연속 높이장·해안선·오아시스·사암 단구·경사로, 지역 소품. 같은 물 판정을 충돌과 낚시에 사용한다.
- `biomes.js`, `layout.js`: 기존 지역과 새 지형의 공통 높이/충돌. 나무 배치는 나머지 연산 격자를 폐기하고 결정적 난수·넓은 밀도 변화·최소 간격을 사용한다. 문·길·이동 지점 주변을 비운다.
- `public/atlas-frame.js`: 타일 크기와 실제 그림 프레임을 분리한다. 나무/곤충/사막 소품의 실제 범위를 지정하고 겹치는 이웃 실루엣을 런타임에 분리한다. 원본 이미지를 균등 분할해 나무 밑동을 자르지 않는다.
- `asset-layout.js`: 걷기·대각선 시트의 실제 행 경계를 정정. 생성 원본에서 인접 행이 맞닿은 일부 프레임은 여전히 재작화가 필요하다. 모든 애니메이션을 새로 그린 상태는 아니다.
- `public/movement-client.js`: 서버 승인 구르기 시작/끝 좌표를 320ms 동안 화면에서 보간한다. `movement-server.js`는 구르기 중 일반 걷기를 중복 누적하지 않는다.
- `public/camera-director.js`: 이동 방향 선행, 차징 줌, 보스 구도, 장소별 주변 흐림. 전투 중 장소 흐림을 중단하고 움직임 감소 설정을 따른다.
- `public/continent-map.js`: M 지도에 국가·지역의 공간 연결도와 방문/현재 위치를 표시. 이동 버튼을 가장한 순간이동은 제공하지 않는다.
- `interest.js`: 발견 지점은 근처 또는 나침반 범위에서 갱신. UI에서 히든 전직을 먼저 안내하는 문구를 제거했다. 소스 공개 기반 웹 게임의 완전한 데이터마이닝 방지를 뜻하지 않는다.

## 지역과 원작 구분

원작 자료: 사용자 제공 `KakaoTalk_Longtxt_20261101_1200_47_608.txt`, 이후 사용자 정정 사항.
요드린 제국·세라프 신성국·해동은 원문에서 확인했다. 이세리아는 사용자가 북쪽 마왕이라고 지정했다. 황금 사구·북녘 영혼설원·세라프 순례 고원·해동 안개 산록이라는 세부 지명과 위치는 개발용 보충 설정이다. 기존 야외 9지역에 4지역을 연결했다. 수도나 각국의 전체 문명/퀘스트가 완성된 것은 아니다.

새 지역에는 양방향 포털, 통행 판정, 발견 재료, 서식 몬스터, 낚시 가능한 물가가 연결되어 있다. 새 지역의 고유 주민·도시·장편 이야기·음악 전환 완성은 다음 단계다. 기존 생활 콘텐츠와 도구 사용은 유지한다. 영구 저장 서비스는 사용자 요청에 따라 새로 도입하지 않았다.
